# LiftTrack
Next.js + Supabase fitness app: ranks, XP, streaks, calories, friends leaderboard.
1. Supabase: new project, SQL Editor, run `supabase/schema.sql`. (Optional: Authentication > Providers > Email > turn off "Confirm email".)
2. Vercel: import this GitHub repo, add env vars `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` (Supabase > Project Settings > API), deploy.
3. iPhone: open the Vercel link in Safari > Share > Add to Home Screen.
